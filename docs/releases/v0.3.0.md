# StockPilot v0.3.0 — Reporting Foundations & Analytics Safety

## Release status

`v0.3.0` is the next pre-1.0 milestone after the v0.2.x reporting series. This release establishes reusable reporting primitives for bounded periods, pagination limits, and period-over-period comparisons.

## Highlights

- Added a dependency-free `internal/reporting` package.
- Added bounded inclusive reporting periods with 1–365 day validation.
- Added deterministic previous-period calculation for comparable windows.
- Added period-over-period delta and percentage helpers.
- Explicitly represent percentage changes with a zero baseline as undefined instead of inventing a percentage.
- Added centralized limit/offset validation helpers.
- Added safe parsing for non-negative integer query parameters.
- Added focused unit coverage for period, trend, and bounds behavior.
- Documented the new reporting primitives and their read-only contract.

## Compatibility

- Existing API routes remain unchanged.
- No database migration is introduced by this milestone.
- No automatic purchasing or inventory mutation is introduced.
- Reporting primitives do not perform database access.

## Reliability and security

- Date windows and result bounds are explicitly constrained.
- Previous-period calculations use the same number of days as the current period.
- Zero-baseline percentage changes remain undefined, avoiding misleading analytics.
- Helpers accept only non-negative pagination offsets and bounded limits.
