# StockPilot v0.5.4 — API Metadata & Reporting Route Hardening

**Release version:** `0.5.4`  
**Previous version:** `0.5.3`  
**Release date:** September 9, 2026  
**Release type:** Patch / regression hardening

## Overview

StockPilot v0.5.4 is a focused maintenance release that hardens release metadata consistency and protects the reporting route registration while preserving the existing v0.5.3 reporting behavior.

## Highlights

- aligned `/api/v1/meta` with release version `0.5.4`;
- aligned the API metadata regression test with `0.5.4`;
- preserved the existing replenishment-readiness route registration independently of optional reporting insights wiring;
- retained the authenticated reporting regression coverage introduced in v0.5.3;
- kept the change set free of database migrations and production-data test dependencies;
- bumped the repository `VERSION` file to `0.5.4`;
- documented the release-hardening milestone.

## Reliability

The release is intentionally small. It does not change inventory mutation rules, purchase-order lifecycle behavior, reporting authorization semantics, or database schema. The route-registration adjustment prevents a refactor from accidentally making the existing replenishment-readiness endpoint depend on optional report-repository wiring.

## Validation

The final release commit should pass the complete CI gate:

- Go module consistency;
- Go formatting;
- `go vet`;
- race-enabled Go tests;
- backend build;
- frontend installation, type checking, and build;
- PostgreSQL migration smoke testing;
- Chromium Playwright browser E2E testing;
- CodeQL/security checks where configured.

The Git tag should only be published after the complete final CI run is green.

## Upgrade

Users upgrading from StockPilot v0.5.3 can update to v0.5.4 as a patch release. No database migration is introduced by this milestone.
