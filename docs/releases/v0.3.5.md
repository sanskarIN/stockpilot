# StockPilot v0.3.5

## Reporting Query Options & Repository Bounds

v0.3.5 introduces the additive repository contract needed to carry validated reporting periods and pagination bounds toward storage-backed analytics.

### Highlights

- added `internal/reporting.Query` for optional `from`/`to` values and pagination bounds;
- added `repository.BoundedReports` as an additive capability;
- existing `repository.Reports` implementations remain source-compatible;
- added unit coverage for time-based and non-time-based query semantics;
- established v0.3.6 as the storage-side execution milestone;
- preserved existing JSON and CSV response contracts;
- kept reporting read-only with no database migration.

### Compatibility

This release deliberately avoids changing the existing `Reports` interface. Repository implementations can adopt `BoundedReports` incrementally, allowing future storage-side period and offset execution without forcing an immediate interface-breaking migration.
