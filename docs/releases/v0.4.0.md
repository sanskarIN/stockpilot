# StockPilot v0.4.0

## Replenishment Performance & Operational Analytics

v0.4.0 expands StockPilot's reporting layer with a repository-backed replenishment-performance report focused on measurable purchase-order execution.

### Highlights

- added `repository.ReplenishmentReports` as an additive capability;
- added PostgreSQL-backed supplier replenishment-performance analytics;
- added exact `from`/`to` period handling for the new report;
- added ordered, received, outstanding, fill-rate, on-time, late, and average-lead-time metrics;
- added deterministic `limit`/`offset` pagination to the new report;
- added `GET /api/v1/reports/replenishment-performance`;
- preserved existing report response contracts and legacy repository interfaces;
- added HTTP regression coverage for query propagation and invalid pagination;
- added PostgreSQL integration coverage for receipt, fill-rate, timeliness, and explicit-period semantics;
- kept the feature read-only with no database migration;
- documented the analytical limits of recommendation-effectiveness claims.

### Compatibility

This release is additive. Existing clients and repository implementations can continue using the previous reporting capabilities. The new endpoint is available only when the configured repository implements `repository.ReplenishmentReports`.

### Verification gate

The v0.4.0 tag should only be published after the final commit passes the complete CI pipeline and CodeQL.
