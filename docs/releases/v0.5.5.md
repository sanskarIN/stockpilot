# StockPilot v0.5.5 — Release Metadata Consistency Hardening

## Summary

StockPilot v0.5.5 is a focused release-hardening patch that prevents release-version drift between repository metadata, the public API metadata endpoint, and its regression test.

## Changes

- Added `scripts/check-release-consistency.sh` as a validation-only release metadata checker.
- Added `make release-check` for local release verification.
- Added a dedicated GitHub Actions release-consistency job.
- Aligned `VERSION` with `0.5.5`.
- Aligned `GET /api/v1/meta` with `0.5.5`.
- Aligned `internal/httpapi/meta_version_test.go` with `0.5.5`.
- Documented the release metadata consistency contract in `docs/API_COMPATIBILITY.md`.
- Added this release note and the corresponding changelog entry.

## Compatibility

- No `/api/v1` breaking changes.
- No request or response contract changes beyond the release metadata value.
- Existing reporting, inventory, purchasing, authentication, and audit behavior is unchanged.

## Database

- No database migration.
- No production-data test dependency.

## Verification policy

The release consistency checker is read-only. It verifies that the three release-version sources agree and exits non-zero when they do not.

The complete applicable GitHub Actions suite must pass on the final release commit before the `v0.5.5` tag is published. Until those checks are observed, the release must not be described as fully verified.

## Upgrade

Upgrade from v0.5.4 to v0.5.5 normally. No database migration or data transformation is required.
