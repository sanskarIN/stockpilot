# StockPilot v0.5.8 — Release Gate Generalization & Verification Baseline

StockPilot v0.5.8 is a focused patch release that removes release-process drift discovered during the v0.5.7 verification cycle and makes the repository release-readiness gate follow the active `VERSION` automatically.

## Highlights

- Generalized `scripts/check-release-readiness.sh` so it derives the expected release version from `VERSION` instead of being hard-coded to v0.5.6.
- Kept the release-readiness checker strict about the presence of the matching changelog entry and release document.
- Aligned `VERSION`, `/api/v1/meta`, and the API metadata regression test with `0.5.8`.
- Made the Makefile release-readiness help text version-neutral.
- Added this dedicated v0.5.8 release record.

## Reliability and safety

- Release-readiness validation is deterministic and validation-only.
- No production credentials are required.
- No production data is required.
- No database migration is introduced by this patch.
- No intentional breaking `/api/v1` contract change is introduced.
- The generalized checker reduces the risk of future patch releases silently validating against stale release metadata.

## Required verification gate

The v0.5.8 release is **not considered stable or publishable** until the final main commit passes all applicable checks, including:

```text
make release-check
make release-readiness
make vet
make test
make build
make web-build
```

Also require successful applicable Browser E2E, PostgreSQL migration/readiness smoke testing, CodeQL/security checks, Android checks, and extension checks where configured for the repository.

## Release integrity rule

Do not create or move the `v0.5.8` tag until the final release commit has a green applicable CI/security gate. Do not describe the release as fully verified based only on local inspection or an earlier commit.

## Upgrade

Upgrade normally from v0.5.7. No database migration or data transformation is required.
