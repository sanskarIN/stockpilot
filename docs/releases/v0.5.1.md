# StockPilot v0.5.1 — Authenticated Mutation Regression Hardening

**Version:** `v0.5.1`
**Release type:** Stable after the complete CI gate passes
**Focus:** Authenticated mutation workflow reliability

## Included

- Deterministic Playwright coverage for authenticated catalog product creation.
- Deterministic Playwright coverage for authenticated inventory stock-in.
- Request-payload assertions for representative catalog and inventory mutations.
- Synthetic browser fixtures with no production credentials or real application data.
- Release metadata aligned to `0.5.1`.
- API metadata regression coverage aligned to `0.5.1`.

## Reliability goals

The release extends the v0.5.0 authenticated navigation foundation into real mutation paths while preserving the existing server-authoritative validation, authorization, CSRF, and audit behavior.

The browser tests deliberately intercept API calls and verify the UI contract without modifying a real StockPilot environment.

## Validation gate

Before publishing the `v0.5.1` Git tag, verify the repository's complete CI pipeline, including:

- Go quality checks;
- web typecheck/build;
- PostgreSQL migration smoke tests;
- deterministic Chromium browser E2E tests;
- CodeQL/security analysis;
- dependency and repository checks already configured by the project.

## Scope intentionally deferred

- Authenticated purchase-order create/submit/receive E2E coverage.
- Complete authenticated reporting fixtures.
- Android authentication and critical-read instrumentation tests.
- Full accessibility audit.
- Production restore and migration rollback rehearsal.
- Reproducible release artifacts.

These remain explicit follow-up work rather than being represented as completed by this release.

## Security & privacy

All new browser fixtures use synthetic identities and synthetic inventory/catalog data. No production credentials, personal information, or real user account data are required.
