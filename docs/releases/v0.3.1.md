# StockPilot v0.3.1

## Reporting API Integration & Metadata

v0.3.1 is the first integration milestone after the v0.3.0 reporting foundation.

### Goals

- integrate shared reporting period validation into public reporting endpoints;
- expose report execution metadata consistently;
- standardize bounded pagination parameters;
- preserve deterministic ordering and cancellation behavior;
- keep existing consumers compatible through additive response fields.

### Reliability

- reject malformed or out-of-range reporting windows;
- keep result bounds explicit and server-controlled;
- propagate request cancellation and deadlines;
- keep CSV responses formula-safe and non-cacheable;
- avoid leaking database implementation details in public errors.

### Safety

- reporting remains read-only;
- no automatic purchasing or inventory mutation;
- no database migration unless evidence demonstrates that it is necessary.
