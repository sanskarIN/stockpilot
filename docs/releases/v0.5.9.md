# StockPilot v0.5.9 — Release Metadata & Documentation Consistency

StockPilot v0.5.9 is a focused patch release that continues the release-integrity work from v0.5.8. It removes stale current-version information from the README and aligns repository/API/test release metadata with `0.5.9`.

## Highlights

- Advance the repository `VERSION` from `0.5.8` to `0.5.9`.
- Align `/api/v1/meta` with `0.5.9`.
- Align the API metadata regression test with `0.5.9`.
- Correct the README's stale `0.2.6` current-development version reference.
- Add this dedicated v0.5.9 release record.
- Retain the version-aware release-readiness and release-consistency checks established in v0.5.8.

## Reliability and safety

- No database migration is introduced by this patch.
- No production credentials are required for release metadata validation.
- No production data is required for release metadata validation.
- No intentional breaking `/api/v1` contract change is introduced.
- Release consistency remains validation-only.
- Release readiness derives its expected version from `VERSION` rather than a hard-coded patch number.

## Required verification gate

The v0.5.9 release is **not considered stable or publishable** until the final main commit passes all applicable checks, including:

```text
make release-check
make release-readiness
make vet
make test
make build
make web-build
```

Also require successful applicable Browser E2E, PostgreSQL migration/readiness smoke testing, CodeQL/security checks, Android checks, and extension checks where configured for the repository.

For local Go module verification, the release-readiness checker also runs:

```text
go mod verify
```

## Release integrity rule

Do not create or move the `v0.5.9` tag until the final release commit has a green applicable CI/security gate. Do not describe the release as fully verified based only on metadata inspection or an earlier commit.

## Upgrade

Upgrade normally from v0.5.8. No database migration or data transformation is required for this patch.
