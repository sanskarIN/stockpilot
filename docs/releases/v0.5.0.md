# StockPilot v0.5.0 — Authenticated Workflow Reliability

## Focus

v0.5.0 expands browser reliability beyond the dashboard shell by validating entry into the primary authenticated operational workspaces with deterministic synthetic API fixtures.

## Included

- Playwright coverage for authenticated navigation into Products, Inventory, Purchase Orders, Warehouses, Lot Inventory, and Audit.
- Deterministic in-browser API fixtures with no production credentials or real application data.
- Regression coverage for returning from each primary workspace to the dashboard.
- Release metadata aligned to `0.5.0`.

## Validation scope

This milestone validates workspace entry and navigation contracts. It does not claim that authenticated create, edit, receiving, inventory mutation, or complete reporting workflows are fully automated yet.
