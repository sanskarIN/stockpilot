# StockPilot v0.3.2 — Reporting API Contract & Version Alignment

## Release focus

v0.3.2 connects the reusable reporting foundation to the HTTP API boundary without changing existing JSON response bodies or transactional behavior.

## Included

- shared validation for reporting `from` and `to` timestamps;
- default 30-day reporting window when no period is supplied;
- shared limit and offset validation with bounded limits;
- response headers for report generation time, requested period, pagination bounds, and completeness;
- HTTP 400 responses for malformed or incomplete report parameters;
- `/api/v1/meta` version alignment with the repository `VERSION` marker;
- focused regression coverage for the request and metadata contract.

## Compatibility

Existing reporting JSON payloads remain unchanged. Metadata is delivered through HTTP response headers so clients that only decode the existing response body continue to work.

## Safety

The milestone is read-only. It does not mutate inventory, purchasing, suppliers, or audit data and introduces no database migration.

## Reporting headers

Successful reporting responses may include:

- `X-Report-Generated-At`
- `X-Report-From`
- `X-Report-To`
- `X-Report-Limit`
- `X-Report-Offset`
- `X-Report-Complete`
