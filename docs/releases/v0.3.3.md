# StockPilot v0.3.3

## Reporting Repository Integration

v0.3.3 continues the reporting work from v0.3.2 by tightening the boundary between HTTP validation and repository-backed analytics.

### Highlights

- validated reporting periods and pagination remain centralized at the HTTP boundary;
- report handlers preserve request cancellation through `r.Context()`;
- repository implementations are expected to apply deterministic ordering for bounded report results;
- existing JSON and CSV response bodies remain unchanged;
- reporting remains read-only and does not introduce inventory or purchasing mutations;
- no database migration is required for this milestone.

### Compatibility

The release is additive. Existing report response payloads remain compatible. Reporting clients can use the metadata response headers introduced in v0.3.2 without changing their existing JSON parsing.
