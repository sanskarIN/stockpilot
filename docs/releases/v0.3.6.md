# StockPilot v0.3.6

## Repository Query Execution

v0.3.6 adds concrete PostgreSQL support for the additive bounded reporting capability introduced in v0.3.5.

### Highlights

- implemented bounded supplier-performance repository execution;
- implemented bounded warehouse-valuation repository execution;
- validated query bounds before repository execution;
- carried supplier `From`/`To` values into the existing reporting window calculation;
- applied requested offsets and limits while retaining the legacy `Reports` interface;
- preserved deterministic ordering and context cancellation behavior;
- added no database migration;
- kept reporting read-only.

### Compatibility

The existing `repository.Reports` interface remains unchanged. `repository.BoundedReports` is additive, so existing repository consumers can continue using the legacy methods while newer callers adopt bounded execution incrementally.

### Important implementation note

The v0.3.6 adapter preserves the legacy SQL implementations and applies the new offset at the repository result boundary. This is an incremental compatibility step; future work can move offset directly into SQL once all report query implementations can share the same bounded query contract.
