# StockPilot v0.5.3 — Authenticated Reporting Workspace Hardening

**Release version:** `0.5.3`  
**Previous version:** `0.5.2`  
**Release date:** September 9, 2026  
**Release type:** Patch / regression hardening

## Overview

StockPilot v0.5.3 expands authenticated browser regression protection across the Reports & Analytics workspace. The reporting UI now has deterministic end-to-end coverage for its complete read-only report-loading surface.

## Highlights

- Added authenticated Playwright coverage for the Reports & Analytics workspace.
- Added deterministic fixtures for report overview metrics.
- Added inventory valuation report fixtures and rendered-value assertions.
- Added inventory aging report fixtures and rendered bucket assertions.
- Added stock movement history fixtures and workspace assertions.
- Added supplier performance fixtures and rendered supplier assertions.
- Added replenishment readiness fixtures and rendered risk-workspace assertions.
- Added replenishment review-history fixtures and empty-state assertions.
- Kept all reporting E2E data synthetic and independent of production credentials/data.
- Bumped the repository version to `0.5.3`.
- Updated the roadmap and changelog for the reporting regression milestone.

## Reliability

This release strengthens browser-level protection around the existing read-only reporting contracts. It does not introduce new production mutation behavior, change reporting authorization semantics, or use live credentials in E2E tests.

## Validation

The release is intended to pass the repository CI gate covering:

- Go module consistency.
- Go formatting.
- `go vet`.
- Race-enabled Go tests.
- Backend build.
- Frontend installation, type checking, and build.
- PostgreSQL migration smoke testing.
- Chromium Playwright browser E2E testing.

The final release tag should only be published after the complete CI run for the final release commit is green.

## Upgrade

Users upgrading from StockPilot v0.5.2 can update to v0.5.3 as a patch release. No database migration is introduced by this milestone.
