# StockPilot v0.3.8

## SQL-Native Pagination & Query Optimization

v0.3.8 moves bounded reporting pagination into PostgreSQL so the database returns only the requested page instead of returning an expanded result set for application-side slicing.

### Highlights

- supplier-performance bounded queries now use SQL `LIMIT` and `OFFSET`;
- warehouse-valuation bounded queries now use SQL `LIMIT` and `OFFSET`;
- deterministic report ordering is retained for stable page boundaries;
- warehouse valuation totals remain complete and independent of item-page slicing;
- request cancellation continues through the PostgreSQL context;
- the additive `repository.BoundedReports` contract remains unchanged;
- legacy `repository.Reports` behavior remains available to existing callers;
- existing JSON and CSV response bodies remain unchanged;
- no database migration was added;
- reporting remains read-only.

### Compatibility

This release is additive. Existing callers using the legacy reporting methods are unaffected. The bounded capability continues to be optional and can be adopted incrementally.

### Verification

CI must pass Go formatting, vetting, tests, server build, web typecheck/build, PostgreSQL migration smoke tests, and CodeQL before the `v0.3.8` tag is considered releasable.
