# StockPilot v0.5.7 — Browser E2E Regression Repair & Release Integrity

StockPilot v0.5.7 is a focused patch release that repairs a concrete browser E2E regression discovered immediately after v0.5.6 and realigns release metadata for the next verified release baseline.

## Highlights

- Restored the complete authenticated browser E2E mutation-workflow suite.
- Removed the malformed top-level Playwright assertion that caused `ReferenceError: expect is not defined` during CI collection.
- Preserved deterministic synthetic fixtures for catalog, inventory, purchasing, and reporting workflows.
- Preserved the strict, deterministic `₹1,500.00` report assertion.
- Preserved the replenishment-readiness synthetic fixture required by the reports workspace.
- Aligned `VERSION`, `/api/v1/meta`, and the API metadata regression test with `0.5.7`.
- Added this dedicated v0.5.7 release record.

## Reliability and safety

- No production credentials are required for the browser E2E suite.
- Browser E2E data remains synthetic and offline from production services.
- No database migration is introduced by this patch.
- No intentional breaking `/api/v1` contract change is introduced.
- Release verification remains validation-only with respect to application and production data.

## Required verification gate

The v0.5.7 release is **not considered stable or publishable** until the final main commit passes all applicable checks, including:

```text
make release-check
make release-readiness
make vet
make test
make build
make web-build
```

Also require successful applicable Browser E2E, PostgreSQL migration/readiness smoke testing, CodeQL/security checks, Android checks, and extension checks where configured for the repository.

## Release integrity rule

Do not create or move the `v0.5.7` tag until the final release commit has a green applicable CI/security gate. Do not describe the release as fully verified based only on local inspection or an earlier commit.

## Upgrade

Upgrade normally from v0.5.6. No database migration or data transformation is required.
