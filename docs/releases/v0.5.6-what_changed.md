# StockPilot v0.5.6 — What Changed

## Scope

v0.5.6 is a release-hardening milestone. It adds deterministic checks around release metadata, repository readiness, Go module integrity, and backend verification without changing production workflow contracts.

## Implementation changes

- Added `scripts/check-release-readiness.sh`.
- Added `make release-readiness`.
- Added `make release-verify`.
- Added `.github/workflows/release-readiness.yml`.
- Updated `VERSION` from `0.5.5` to `0.5.6`.
- Added `docs/releases/v0.5.6.md`.

## Validation coverage

- Semantic version validation.
- Changelog/release-document presence checks.
- Release metadata consistency validation.
- Go module integrity verification.
- `go vet ./...`.
- Race-enabled backend tests.
- Reproducible backend build command.

## Safety boundaries

- No database migration.
- No production-data dependency.
- No production credential dependency.
- No intentional API-breaking change.
- No intentional authentication, inventory, purchasing, reporting, Android, web, or extension workflow redesign.

## Release discipline

The release must not be tagged or published until the final release commit passes the applicable CI and security checks. Any failure discovered during verification is a release blocker and should be fixed before publication.
