# StockPilot v0.5.2 — Purchase Order Lifecycle Regression Hardening

**Release version:** `0.5.2`  
**Previous version:** `0.5.1`  
**Release date:** September 8, 2026  
**Release type:** Patch / regression hardening

## Highlights

- Fixed the authenticated product-creation E2E failure caused by an ambiguous `Unit` locator under Playwright strict mode.
- Added deterministic authenticated purchase-order creation coverage.
- Added authenticated purchase-order submission/status mutation coverage.
- Added authenticated purchase-order receiving coverage.
- Added request-payload assertions for purchase-order creation, submission, and receipt mutations.
- Kept all browser lifecycle fixtures synthetic and independent of production credentials and production data.
- Updated `VERSION` and `/api/v1/meta` to `0.5.2`.
- Updated the API metadata regression test to expect `0.5.2`.

## Reliability focus

This release extends the mutation regression boundary from catalog and inventory operations into the purchase-order lifecycle: create → submit → receive.

The browser suite exercises the existing UI and API contracts with deterministic test doubles. It does not change production authorization, lifecycle validation, or persistence rules.

## Validation gate

The final release commit must pass the complete GitHub Actions CI workflow before the `v0.5.2` tag is treated as release-ready:

- Go module consistency, formatting, vet, race-enabled tests, and server build.
- Web dependency installation, typecheck, and production build.
- PostgreSQL migration smoke test and readiness check.
- Chromium Playwright browser E2E suite.

## Upgrade

v0.5.2 is intended as a backward-compatible patch release from v0.5.1. No database migration is introduced by this milestone.
